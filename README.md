# Palabras encadenadas

Trabajo Final Integrador de Interfaces de Usuario de la UNQ.

## Instalación

```bash
git clone https://github.com/Matias-fl/unq-ui-matias-flores-trabajo-final.git
cd unq-ui-matias-flores-trabajo-final
npm ci
```

Creá un archivo `.env` a partir de `.env.example`. Ahí se configura `VITE_WORD_API_URL` con la URL de la API de la cátedra.

## Desarrollo

```bash
npm run dev
```

Abrí la dirección que Vite muestra en la terminal.
