# Palabras encadenadas

Trabajo Final Integrador de Interfaces de Usuario de la UNQ.

## Instalación

```bash
git clone https://github.com/Matias-fl/unq-ui-matias-flores-trabajo-final.git
cd unq-ui-matias-flores-trabajo-final
npm i
```



## Ejecucion

```bash
npm run dev
```

Abrí la dirección que Vite muestra en la terminal, generalmente disponible en ```http://localhost:5173```
